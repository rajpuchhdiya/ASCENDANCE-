# Cookie Policy (Template)

This site uses cookies to provide core functionality, remember preferences, and analyze traffic. We only enable analytics and marketing cookies with explicit consent.

Cookie categories

- Necessary: Required for basic site operation (session cookies, login cookies).  
- Preferences: Remember user preferences (language, display).  
- Statistics: Anonymized analytics (GA4) — enabled only with consent.  
- Marketing: Advertising and tracking pixels — enabled only with consent.

How to change your preferences

- Use the cookie banner to change consent preferences at any time. To withdraw consent, clear the relevant cookies or use the cookie settings link in the footer.
